# 👨‍💼 Aura Shop Admin

Admin Dashboard for managing the Aura Shop e-commerce platform. It provides product management, order monitoring, dashboard analytics, and secure admin authentication.

# ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/your-username/AURA-SHOP-Admin.git
```

Install Dependencies

```bash
yarn
```

---

# 🌍 Environment Variables

### .env.development

```env
VITE_API_URL=http://localhost:5000/api
```

### .env.production

```env
VITE_API_URL=https://your-backend-url.onrender.com/api
```

---

# ▶️ Run Project

```bash
yarn dev
```

---

# 📦 Production Build

yarn build
